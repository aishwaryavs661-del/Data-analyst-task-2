## Objective
Create visualizations and derive meaningful insights from the Sample Superstore Sales dataset.

Sample Superstore Sales Data

## Tool Used
Google Sheets

## Dashboard Components
1. Category Analysis
2. Sales Trend Analysis
3. Profit Analysis

## Key Insights
- Office Supplies generated the highest sales among all categories.
- Sales showed variations across different time periods.
- Certain regions contributed more to overall profit than others.
- Profitability varied significantly across product categories.
